## 📖 项目简介

这是我日常学习 Python 的代码仓库，记录了从零开始自学 Python 的完整成长轨迹。  
仓库主要内容涵盖：

- 📘 **Python 基础语法** — 变量、数据类型、字符串操作、输入输出
- 📚 **教材课后习题** — 分章节整理的课本配套练习
- 💻 **在线直播课作业** — 实战项目：抽奖系统、扑克牌比大小等
- 🧪 **日常代码测试** — 各种知识点的验证与探索代码
- 📝 **学习笔记** — 重点知识总结与疑难点突破

> 由于是自学，体系内容可能不是特别完整，但会持续更新。欢迎各位大佬提意见与建议 🙏

## 🧠 为什么选择 Python？

- **语法简洁**：上手快，可读性强，适合编程入门
- **生态庞大**：Web 开发、数据分析、人工智能、自动化测试等领域都有成熟的框架和库支持
- **应用广泛**：从脚本工具到机器学习，Python 无处不在

> 在高速发展的 **AI 时代**，我们更需要不断学习，提升自己的竞争力，不被社会淘汰。  
> 学习的目的是为了提高自己的能力，在社会的大环境中时刻保持竞争力，充分利用所学解决问题。

## 🚀 快速开始

```bash
# 1. 克隆仓库
git clone https://github.com/Chaniug/Python_Learn.git

# 2. 进入项目目录
cd Python_Learn

# 3. （可选）创建虚拟环境
python -m venv venv

# Windows 激活虚拟环境
venv\Scripts\activate

# 4. 安装依赖
pip install -r requirements.txt

# 5. 运行示例（以抽奖系统为例）
python Code/TestFile/Day_stu_file.py
```

## 📅 学习计划

- [x] **基础语法**：变量、数据类型、字符串、输入输出
- [x] **流程控制**：条件判断（if-elif-else）、循环（for、while）
- [x] **数据结构**：列表、集合、字典
- [ ] **函数与模块**：自定义函数、模块导入
- [ ] **文件操作**：读写文件、上下文管理器
- [ ] **面向对象**：类与对象、继承、封装、多态
- [ ] **进阶主题**：异常处理、装饰器、生成器
